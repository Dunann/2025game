# Rye display font

`Rye-Regular.ttf` is the Rye display typeface by Nicole Fally, distributed by Sorkin Type Co under the SIL Open Font License 1.1. The original license is included in `OFL-Rye.txt`.

Source: [Google Fonts — Rye](https://github.com/google/fonts/tree/main/ofl/rye).

The application serves this font locally for its poker-style starting screen; it does not request fonts from an external service while playing.
